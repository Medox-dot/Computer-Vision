# K-Means Clustering Task

## Project Description
This project implements the K-Means Clustering algorithm using Python on virtual data points.

## Dataset
150 virtual data points generated using make_blobs.

## Algorithm
K-Means Clustering

## Number of Clusters
K = 3

## Libraries Used
- NumPy
- Matplotlib
- Scikit-learn

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Run the program:

   python main.py

## Output
A scatter plot showing three clusters with their centroids.
